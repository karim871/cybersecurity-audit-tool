# Changelog

All notable changes to this project will be documented in this file.

## [2.0.0] - 2025-01-04

### Added
- Real-time progress bars using tqdm
- Comprehensive logging system with multiple levels
- Dataclass-based architecture for better type safety
- Full test suite with 20+ test cases
- Enhanced vulnerability detection with severity levels
- Better error handling and timeout management
- JSON report generation with metadata
- Configurable scan parameters
- Comprehensive documentation and learning exercises

### Changed
- Refactored code into modular classes
- Improved scanning performance
- Better console output formatting
- Enhanced command-line help

### Fixed
- False positive reduction
- More robust error handling
- Better timeout behavior
